Gestures & Physics Motion

터치 제스처 & UI 물리 모션 패턴

프롬프트나 디자이너-개발자 협업 시 원하는 타이밍 곡선과 모션 이름을 정확히 지정해 보세요.

01 이즈 인 (Ease-in) 가속 곡선
처음엔 느리게 끝에서 최고속도
출발지 도착지

출발할 때 서서히 가속하여 끝으로 갈수록 빨라집니다. 중력을 받아 떨어지는 물체나 화면 밖으로 퇴장(Exit)할 때 주로 사용됩니다.

화면 밖 퇴장 / 가속
02 이즈 아웃 (Ease-out) 가장 자연스러운 감속
끝에서 느리게 UI 등장 표준
출발지 부드러운 안착

빠르게 진입한 뒤 목적지에 다다를수록 부드럽게 감속합니다. 사용자의 시야에 새로운 UI 요소가 등장(Enter)할 때 가장 눈이 편안합니다.

화면 진입 표준 감속
03 스프링 (Spring) 물리 엔진 기반
넘쳤다가 멈춰요 오버슈트(Overshoot)
출발지 목표점(통과 후 반동)

목표 지점을 살짝 지나쳤다가(Overshoot) 고무줄처럼 튕기며 안착합니다. 애플 iOS와 현대 UI에서 경쾌하고 쫀득한 인터랙션을 줄 때 필수입니다.

탄성 있는 탄력 모션
04 바운스 (Bounce) 바닥 충돌 반동
공처럼 통통 튀는 움직임
충돌 피드백 (낙하 시)

물체가 단단한 바닥에 닿았을 때 통통 튀어 오르는 반동 효과입니다. 팝업 강조, 완료 뱃지 낙하, 주의 유도 요소에 경쾌한 재미를 줍니다.

통통 튀는 충돌 효과
05 순차 등장 (Stagger) 시간차 계단식 노출
오늘 할 일
1 이력서 최종 검토
2 포트폴리오 업로드
3 모의 면접 일정 예약

목록의 카드나 요소들이 한 번에 퍽 뜨지 않고, 위에서부터 약 0.05~0.1초 시차(Delay)를 두고 차례대로 미끄러지듯 나타납니다.

리스트/피드 시차 노출
06 페이드 (Fade) 투명도(Opacity) 변화

서서히 사라지고
서서히 나타남

현재 투명도: 100% (완전 노출)

위치 이동 없이 투명도(Opacity)만 조절하여 부드럽게 나타나거나(Fade-in) 사라집니다(Fade-out). 모달 배경 딤(Dim) 처리에 기본 적용됩니다.

투명도 전환 기본
07 슬라이드 (Slide) 방향성 위치 이동

좌우 또는 상하 축을 따라 미끄러져 들어옴

화면의 상·하·좌·우 한 방향에서 매끄럽게 미끄러지듯 진입합니다. 바텀시트, 사이드 네비게이션 서랍(Drawer), 토스트 알림의 핵심 모션입니다.

서랍 / 바텀시트 진입
08 확대 전환 (Zoom) 크기 확장 포커스

특정 요소의 Scale(비율)을 순간적으로 키워 화면의 중심으로 확장합니다. 카드 클릭 시 상세 페이지로 펼쳐질 때 깊이감(Depth)을 형성합니다.

상세 펼침 / 포커스
09 공유 요소 전환 (Shared) 매직 모션 (연속성)
포트폴리오 상세
목록의 작은 썸네일이 화면 전환 시 사라지지 않고 상세 뷰의 메인 배너로 자연스럽게 확장됩니다.

이전 화면의 이미지나 카드가 다음 화면의 대표 영역으로 끊김 없이 형태를 변형(Morphing)하며 이어져 시각적 맥락의 단절을 완전히 없앱니다.

화면 간 끊김 없는 연결
10 패럴랙스 깊이 스크롤 Parallax depth scroll
⚡
움직임 10 패럴랙스 깊이 스크롤
배경과 전경 레이어의 스크롤 속도 차 입체감
Parallax depth scroll

스크롤 시 배경 이미지는 천천히 움직이고 전경 카드는 빠르게 올라가며 공간적 깊이감을 연출

구현 힌트: 스크롤 시 배경 이미지는 천천히 움직이고 전경 카드는 빠르게 올라가며 공간적 깊이감을 연출 (배경과 전경 레이어의 스크롤 속도 차 입체감 특성 준수)
Mobile Touch Gestures
