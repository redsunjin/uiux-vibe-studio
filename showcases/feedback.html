시스템 알림 & 피드백 레이어 패턴

카드의 ‘작동해보기’ 버튼을 눌러 각 UI 컴포넌트의 실제 동작 방식과 시각적 반응을 확인해 보세요.

01 토스트 (Toast) 방해도: 낮음
포폴을 저장했어요

일시적으로 하단에 노출된 뒤 2~3초 후 자동 소멸합니다. 사용자의 진행 흐름을 가로막지 않는 단순 상태 안내에 적합합니다.

자동 사라짐 / 비침해형
02 스낵바 (Snackbar) 방해도: 낮음~중간
A사 지원서.pdf
B사 포트폴리오.pdf 보관됨
A사 지원서가 삭제되었습니다.

토스트와 유사하지만 메시지 우측에 '실행 취소(Undo)' 등의 보조 액션 버튼을 제공하여 실수를 즉시 되돌릴 수 있습니다.

단일 보조 액션 포함
03 배너 (Banner) 방해도: 중간
서류 마감이 3일 남았어요

화면 상단 영역에 고정되어 사용자가 직접 닫거나 이슈가 해결될 때까지 계속 노출되는 중요 공지 및 상태 표시용 컴포넌트입니다.

지속적 알림 / 상단 고정
04 모달 (Modal dialog) 방해도: 높음

버튼 클릭 시 전체 화면 차단

지원서를 제출할까요?

제출하면 고칠 수 없어요

화면 전체를 Dim(어둡게) 처리하고 중요한 결정을 강제합니다. 사용자의 실수나 비가역적(되돌릴 수 없는) 행동을 방지할 때 사용합니다.

화면 차단 / 중요 결정
05 바텀시트 (Bottom sheet) 방해도: 중간~높음
작업 파일 메뉴

모바일 화면 하단에서 슬라이드 업되어 추가 메뉴나 세부 작업 옵션을 손쉽게 선택할 수 있도록 돕는 모바일 친화적 인터페이스입니다.

모바일 최적화 메뉴
06 인라인 오류 (Inline error) 방해도: 낮음

이메일 형식을 확인해 주세요

입력 필드 바로 아래에 붉은색 경고문구를 띄워 문제가 발생한 지점과 원인을 직관적으로 안내하는 실시간 폼 검증 방식입니다.

입력창 직하단 검증
07 툴팁 (Tooltip) 방해도: 매우 낮음
서류 합격률
24%
최근 3개월 지원 기준이에요

마우스 호버나 물음표 아이콘 터치 시 말풍선 형태로 보조 설명을 제공합니다. 화면을 어지럽히지 않고 용어나 산정 기준을 설명합니다.

보조 설명 풍선
08 코치마크 (Coach mark) 방해도: 중간~높음

여기서 포폴을 올려요

새 포트폴리오를 빠르게 등록해보세요

신규 기능이나 앱 최초 온보딩 시 특정 버튼을 하이라이트하고 주변 배경을 어둡게 만들어 사용자의 시선과 행동을 유도합니다.

온보딩 / 튜토리얼
