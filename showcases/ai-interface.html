생성형 AI & 스트리밍 인터페이스 패턴

생성형 AI 대화창의 핵심 UI 패턴을 직접 클릭 & 시뮬레이션하여 확인해 보세요.

01 생각 중 표시 추론 대기 인디케이터

답변을 고민하고 있어요

모델이 프롬프트를 분석하고 복잡한 추론(Reasoning) 과정을 거칠 때, 멈추지 않고 작업 중임을 3개의 점이나 문구로 안내합니다.

추론 중 피드백
02 스트리밍 답변 체감 반응 극대화
제주 여행 일정 짜줘
성산 일출봉과 협재 해수욕장을 추천해요!

전체 텍스트 생성이 완료될 때까지 기다리지 않고, 단어(토큰) 단위가 생성되는 즉시 화면에 타자기처럼 실시간 스트리밍합니다.

토큰 실시간 출력
03 추천 질문 칩 프롬프트 탐색 가이드

이렇게 물어볼 수 있어요

선택된 프롬프트가 입력창에 채워졌어요!

무엇을 질문해야 할지 막막한 사용자에게 맥락에 맞는 질문 후보를 칩(Chip) 버튼으로 제안하여 대화 시작 장벽을 낮춥니다.

온보딩 / 넥스트 액션
04 다시 생성 버전 분기 및 재생성

첫날은 동쪽, 둘째 날은 서쪽으로 가보세요.

1 / 2

답변이 만족스럽지 않을 때 다른 톤앤매너나 관점으로 다시 작성하도록 요청하며, 이전 버전과 최신 버전을 비교 탐색할 수 있습니다.

버전 비교 인디케이터
05 출처 표시 할루시네이션 완화

성산 일출봉은 아침 7시 전이 한산해요

근처 해장국집도 들러 보세요

출처 1: 제주관광공사 공식 가이드

웹 검색이나 문서 검색(RAG) 기반의 응답에서 어떤 출처(도메인, 기사)를 참고했는지 각주나 링크 칩으로 표시하여 신뢰도를 부여합니다.

참고 문헌 / RAG 검증
06 답변 피드백 RLHF 데이터 수집

3일 일정을 하루씩 나눠 드릴게요

평가를 남겨보세요

좋아요(Thumbs up)/싫어요(Thumbs down) 버튼을 제공하여 답변 품질을 평가받고, 인간 피드백 기반 강화학습(RLHF) 데이터로 활용합니다.

좋아요 / 싫어요 평가
07 고쳐 묻기 대화 분기점 수정
일정 짜줘

이미 보낸 이전 질문을 편집하여 새로운 대화 분기(Branch)를 생성합니다. 오타를 고치거나 조건을 덧붙여 다시 물어볼 때 필수적입니다.

과거 질문 재편집
