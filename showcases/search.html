Search & Filtering Patterns

통합 검색 & 필터·정렬 패턴

검색 시작 전부터 결과 탐색까지, 검색 UX 컴포넌트를 직접 입력하고 클릭해 보세요.

01 검색창 (Search bar) 탐색 시작점 + 지우기(X)

돋보기 아이콘 + 플레이스홀더 힌트 + 한 번에 지우기(X) 버튼으로 구성됩니다.

사용자가 검색어를 입력하는 기본 인풋 박스입니다. 포커스 시 테두리가 강조되며, 한 글자라도 입력되면 우측에 즉시 삭제(`X`) 버튼이 나타나야 합니다.

05 필터 (Filter) 결과 범위 좁히기
가격 범위 3만 원 ~ 12만 원

수천 개의 검색 결과 중에서 가격대, 브랜드, 색상, 무료배송 여부 등 원하는 조건에 맞는 항목만 남기고 나머지를 걸러냅니다.

다중 조건 좁히기
06 정렬 (Sort) 노출 순서 재배열

필터와 달리 **전체 결과 개수는 줄이지 않고**, ‘추천순 · 낮은 가격순 · 리뷰 많은순 · 최신순’ 등 나열되는 순서만 바꿉니다.

결과 개수 유지 · 순서 변경

검색 결과 제목이나 본문 요약에서 **내가 입력한 검색어가 어느 위치에 포함되어 있는지** 굵은 파란색 글씨나 배경 하이라이트로 즉시 알아보게 합니다.

오타나 재고 부족으로 결과가 0건일 때 단순히 “결과 없음”만 띄우면 이탈합니다. **오타 교정 제안이나 대체 인기 카테고리 버튼**으로 구출해야 합니다.

캠핑 전문 브랜드관 12곳

구현 힌트: 필터/검색 결과 0건일 때 빈 화면 폴백 노출 + 오타 교정/추천 키워드 칩 클릭 시 즉시 재검색 실행
10 적용된 필터 칩 & 초기화 Active filter bar & Reset
최근: 디자인 시스템 ✕ 서울/판교 ✕
전체 초기화

현재 적용 중인 필터 조건들을 상단에 알약 태그로 모아 보여주고 한 번에 해제하는 컨트롤 바

구현 힌트: 활성 필터 조건을 상단 알약 칩으로 렌더링하고 개별 X 해제 및 [전체 초기화] 클릭 시 기본 목록 즉시 복원
11 패싯 카운트 필터 Faceted search sidebar
필터 조건 ▾ 검색 11 패싯 카운트 필터 [추가]
정렬: 정확도순 ▾

체크하기 전에 각 필터 조건 옆에 해당하는 결과 건수를 괄호로 미리 표시해 빈 결과(0건)를 방지

구현 힌트: 패싯 필터 옵션 옆에 현재 조건 기준 예상 결과 건수(예: 브랜드 (12))를 동적으로 계산·표시하고 0건 옵션은 비활성화
