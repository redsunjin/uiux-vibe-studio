Menu & Trigger Icons

메뉴 트리거 & 액션 아이콘 표준

아이콘 모양을 직접 클릭하여 각각의 메뉴 버튼이 어떤 화면이나 옵션 창을 호출하는지 확인해 보세요.

01 햄버거 (Hamburger) 전체 메인 메뉴 / 드로어
전체 카테고리
홈 대시보드
채용 공고 탐색
이력서 관리
좌측 드로어 호출 표준

빵-패티-빵이 겹쳐진 햄버거처럼 가로줄 3개로 이루어진 가장 유명한 아이콘입니다. 화면 상단 구석에서 전체 내비게이션 서랍(Drawer)을 엽니다.

가로선 3개 (≡)
02 케밥 (Kebab) 세로 더보기 옵션

꼬치에 고기를 세로로 꿴 케밥 모양처럼 세로 점 3개(`⋮`)로 구성됩니다. 주로 안드로이드 앱 우측 상단이나 댓글·카드 우측의 '더보기' 메뉴에 쓰입니다.

세로 점 3개 (⋮)
03 미트볼 (Meatballs) 가로 더보기 / 행 액션
| |

접시 위에 나란히 놓인 미트볼 3개(`⋯`) 모양입니다. iOS 환경이나 테이블 행(Row), 노션 블록 우측에서 세부 설정 팝오버를 열 때 가장 흔히 쓰입니다.

가로 점 3개 (⋯)
04 와플 (Waffle) 앱 런처 / 서비스 스위처
Google 워크스페이스 앱 전환
Mail
Drive
Docs

동그란 점 9개가 3×3 격자로 배열된 모양입니다. 구글(Google) 우측 상단의 '앱 런처'처럼 생태계 내의 다른 서비스나 앱으로 이동할 때 표준적으로 사용됩니다.

3×3 원형 점 격자
05 벤토 (Bento) 그리드 뷰 / 대시보드 모듈
바둑판 타일(Grid) 보기로 전환됨

네모난 칸막이가 나뉜 일본식 도시락(Bento) 모양의 3×3 사각형 격자입니다. 앨범·파일 목록을 '바둑판 그리드 뷰'로 전환하거나 모듈 메뉴를 열 때 쓰입니다.

3×3 사각 박스 격자
06 도너 (Döner) 데이터 필터(Filter) 전용
조건 필터링 (깔때기 축소)
경력 3년↑ 서울/판교 재택가능

위에서 아래로 갈수록 폭이 좁아지는 터키식 회전 고기(도너 케밥) 모양입니다. 많은 데이터에서 원하는 조건만 걸러내는 필터(Filter) 아이콘의 글로벌 표준입니다.

역삼각형 깔때기 3선
07 베지 버거 (Veggie burger) 미니멀 모바일 헤더 메뉴

클릭 시 X 닫기 버튼으로 미니멀하게 회전

햄버거에서 고기 패티(가운데 줄)를 뺀 가로줄 2개(`=`) 모양입니다. 애플(Apple) 모바일 웹이나 모던 브랜드 사이트에서 세련되고 간결한 내비게이션 버튼으로 각광받습니다.

가로선 2개 (= ↔ ✕)
08 계단 (Stairs) 정렬(Sort) / 계층 목차
정렬 기준: 최신 등록순 → 마감 임박순

선들이 계단식(Staggered)으로 비스듬히 어긋나 있는 형태입니다. 리스트의 순서 정렬(Sort) 기준을 바꾸거나 문서의 계층형 목차(Outline)를 열 때 사용됩니다.

계단식 오프셋 3선
09 슬라이더 (Sliders) 상세 맞춤 설정 / 환경 제어
희망 연봉 범위 4,500만+

음향 믹서 콘솔의 노브(Knob)가 달린 가로 막대 모양입니다. 단순 필터(도너)보다 정밀한 환경설정(Preferences), 수치 범위 조절, 상세 검색 조건 모달을 호출합니다.

조절 노브가 달린 막대
10 스피드 다이얼 FAB Speed dial FAB
메뉴버튼 10 스피드 다이얼 FAB
📷 🎙 📄 ✕

하단 플로팅(+) 버튼을 누르면 위로 사진·음성·문서 등 하위 빠른 실행 버튼들이 펼쳐짐

구현 힌트: 플로팅(+) 버튼 클릭 시 회전(rotate-45)과 함께 하위 액션 버튼들이 stagger 딜레이로 위로 펼쳐지는 스피드 다이얼 구현

구현 힌트: 주 액션 버튼과 드롭다운(▾) 트리거를 분리 배치하고, ▾ 클릭 시 popover='auto' 보조 옵션 메뉴 노출
