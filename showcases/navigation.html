Navigation Architecture

정보 탐색 & 내비게이션 구조 패턴

모바일 화면 구조를 결정짓는 핵심 내비게이션 인터페이스를 직접 탭하고 스크롤해 보세요.

01 하단 탭바 (Tab bar) 최상위 네비게이션
쇼핑

모바일 앱 화면 최하단에 3~5개 주요 핵심 메뉴를 항시 고정하여, 엄지손가락으로 손쉽게 최상위 화면을 오갈 수 있도록 돕습니다.

엄지 손가락 친화 탭
02 상단 탭 (Top tabs) 동일 위계 하위 분류
저장한 보관함 목록

화면 상단에서 현재 섹션 내의 동일 위계 콘텐츠를 카테고리별로 분할 탐색할 때 사용하며, 좌우 스와이프 제스처와 연동됩니다.

카테고리 분할 필터

햄버거 아이콘(`☰`)을 누르면 좌측(또는 우측)에서 서랍처럼 슬라이드되어 나오는 메뉴로, 사용 빈도가 낮은 보조 기능을 깔끔하게 수납합니다.

사이드 슬라이드 서랍
04 브레드크럼 (Breadcrumb) 위치 경로 추적
> > 무선 이어폰

무선 이어폰

상위 경로로 즉시 이동했습니다.

헨젤과 그레텔의 빵부스러기처럼 사이트 계층 구조에서 현재 위치의 깊이(Depth)를 보여주며, 상위 카테고리로 1클릭 복귀를 지원합니다.

06 플로팅 버튼 (FAB) 최우선 주요 액션(Primary)
새 글 작성 창을 호출합니다!

화면 위에 둥둥 떠 있는 원형/캡슐형 버튼으로, 해당 화면에서 사용자가 취할 가능성이 가장 높은 최우선 행동(글쓰기, 등록 등)을 강조합니다.

화면 위 떠 있는 CTA
07 페이지네이션 (Pagination) 정형화된 번호 이동
게시글 목록 4페이지

방대한 데이터를 특정 페이지 단위(1, 2, 3...)로 분할하여 로드하며, 명확한 목적을 가지고 특정 위치로 직행할 때(검색 결과 등) 안정적입니다.

정확한 위치/푸터 접근

페이지를 바꿀 필요 없이 화면 끝에 도달하면 다음 콘텐츠가 자동으로 덧붙여집니다. 인스타그램, 유튜브, 핀터레스트처럼 탐색 몰입에 특화됩니다.

끝없이 나오는 피드
09 뒤로 가기 (Back navigation) 안전한 이전 복귀
상세 정보
이전 목록 화면으로 복귀했습니다!

상단 좌측의 `<` 화살표나 스와이프 제스처로 직전 화면으로 되돌아갑니다. 사용자가 어디서든 안심하고 깊이 탐색할 수 있게 만드는 안전장치입니다.

이전 화면으로 복귀
10 커맨드 팔레트 (Cmd+K) Command palette (Cmd+K)
⚡ 이동할 페이지나 실행할 명령을 입력하세요... ⌘K

Cmd+K(Ctrl+K)를 누르면 화면 중앙에 떠서 페이지 이동과 액션을 즉시 검색·실행하는 파워유저 바

구현 힌트: Cmd+K / Ctrl+K 단축키로 <dialog> 커맨드 팔레트 오픈, 화살표 위/아래 키 선택 이동 및 Enter 즉시 실행 구현
11 메가 메뉴 Mega menu dropdown
제품 ▾솔루션가격
• 대분류 A• 중분류 B★ 추천 배너

상단 GNB 호버 시 넓은 다단 패널이 펼쳐지며 하위 카테고리 전체를 한눈에 보여주는 메뉴

구현 힌트: 상단 GNB 호버/포커스 시 다단 메가 메뉴 패널 전개, Esc 및 마우스 이탈 지연(150ms) 닫기 처리
