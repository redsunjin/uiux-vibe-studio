3단계로 시작하는 바이브 코딩 흐름

처음 방문하셨다면 아래 순서대로 따라 해보세요. 백지 프롬프트보다 훨씬 일관된 화면 결과물을 얻을 수 있습니다.

1

프리셋 선택 또는 패턴 사전 탐색

8대 도메인 프리셋으로 기본 뼈대를 1초 만에 불러오거나, 패턴 사전에서 적합·주의·비교 가이드를 보고 필요한 블록을 고릅니다.

2

블록 가감 · 기획 메모 · UX 휴리스틱 검수

상단·본문·하단·인터랙션 슬롯에 블록을 조합하고, 인라인 오류·빈 화면·스켈레톤 누락 여부를 휴리스틱 검수로 점검합니다.

3

로컬 미리보기 확인 → AI 프롬프트 복사

로컬 즉시 프리뷰로 화면 뼈대를 먼저 확인한 뒤, 217종 고유 구현 레시피가 담긴 프롬프트를 복사해 AI 코딩 도구에 붙여넣어 완성합니다.

역할별 추천 진입 경로

  • 기획자 · PM: 패턴 사전에서 유사 패턴 비교(예: 모달 vs 바텀시트)와 적합·주의 기준을 확인해 기획서 용어를 통일하세요.
  • 디자이너 · 바이브 코더: 화면 조립기에서 프리셋을 불러와 반응형 뼈대와 구조화된 프롬프트를 생성하세요.
  • 개발자 · AI 에이전트 사용자: uiux-vibe-composer 스킬을 연결해 패턴 ID 기준으로 구현·UX 휴리스틱 검수를 자동화하세요.

로컬 즉시 프리뷰 vs AI 프롬프트 컴파일

• 로컬 즉시 프리뷰: API 키 없이 브라우저에서 레이아웃 골격과 10대 핵심 카테고리 위젯의 배치를 즉시 확인하는 빠른 와이어프레임 미리보기입니다.

• AI 프롬프트 컴파일: 217종 전 패턴의 고유 DOM·상태·접근성 레시피를 포함한 명세서를 생성해, 실제 동작하는 고품질 프로토타입 코드로 완성할 때 사용합니다.

브라우저에서 바로 쓰는 주요 기능

빌드나 서버 설정 없이 정적 웹페이지에서 모든 기능을 바로 실행할 수 있습니다.
