# 도메인별 표준 패턴 조합 프리셋 (Composition Blueprints)

자주 요청되는 6대 도메인 화면을 설계할 때, 208종 카탈로그를 매번 처음부터 조합하지 않고 아래 검증된 세트 구성을 기본 골격으로 채택한 뒤 요구사항에 맞게 가감하세요.

---

## 1. 커머스 통합 검색 · 필터 · 장바구니 플로우
* **권장 뷰포트**: Mobile-first (`nav_01` 하단 탭) → PC (`lay_04` 카드 그리드 + 좌측 필터 사이드바)
* **슬롯 조합**:
  * `header`: `nav_05`(고정 헤더), `src_01`(검색창 + X 클리어), `src_02`(자동완성), `src_09`(범위 탭), `src_10`(적용 필터 칩 & 초기화), `src_06`(정렬)
  * `main`: `src_11`(패싯 카운트 필터), `cnt_02`(상품 카드 그리드), `src_07`(검색어 하이라이트), `com_04`(별점 분포), `com_05`(쿠폰 코드), `com_06`(주문 금액 영수증), `src_08`(0건 결과 없음 폴백), `ld_02`(스켈레톤)
  * `bottom`: `com_02`(하단 고정 구매 바), `com_03`(슬라이드 장바구니 드로어), `fb_02`(장바구니 담기/삭제 스낵바 + Undo)
  * `behavior`: `mo_05`(카드 순차 등장), `ld_07`(찜하기 낙관적 UI)

## 2. 숙박 · 병원 · 서비스 예약 플로우
* **권장 뷰포트**: Mobile (`grid-cols-1`) → Tablet/PC (`lay_03` 또는 좌측 선택 + 우측 요약 영수증 2단)
* **슬롯 조합**:
  * `header`: `nav_09`(뒤로 가기), `ind_02`(단계 위저드: 날짜→옵션→결제), `dt_10`(마감/특가 카운트다운)
  * `main`: `dt_08`(체크인·체크아웃 분할 + N박 계산), `dt_03`(기간 선택 달력), `dt_04`(빠른 선택 칩), `dt_05`(시간 슬롯 + 마감 비활성화), `form_08`(인원 수량 스테퍼), `form_01`(예약자 정보 + `fb_06` 인라인 오류), `com_06`(예상 결제 명세)
  * `bottom`: `ld_09`(예약 확정 로딩 버튼), `fb_04`(예약 확인 `<dialog>` 모달), `fb_01`(예약 완료 토스트)
  * `behavior`: `mo_03`(모달 스프링 전환), `sty_21`(글래스모피즘 요약 카드 선택 가능)

## 3. B2B SaaS 분석 대시보드 & 관리 콘솔
* **권장 뷰포트**: Desktop-first (`lay_05` 좌측 사이드바 + `lay_07` 대시보드, 모바일에선 `nav_03` 드로어 전환)
* **슬롯 조합**:
  * `header`: `nav_05`(고정 헤더), `nav_10`(Cmd+K 커맨드 팔레트), `dt_04`·`dt_03`(조회 기간 선택), `ico_04`(앱 스위처), `fb_09`(알림 뱃지)
  * `main`: `cnt_08`(KPI 요약 카드 + `cht_01` 스파크라인), `cht_03`(막대 비교 차트), `cht_02`(도넛 비중), `cht_05`(전환 퍼널), `cnt_07`(정렬·필터 데이터 테이블), `cnt_12`(우측 인스펙터 상세 패널), `cnt_06`(데이터 없음 빈 화면)
  * `bottom`: `nav_07`(페이지네이션), `fb_02`(행 삭제/상태 변경 스낵바 + Undo)
  * `behavior`: `txt_04`(KPI 숫자 카운트업), `mo_02`(Ease-out)

## 4. 생성형 AI 워크스페이스 (Chat + Artifact Split)
* **권장 뷰포트**: Desktop (`ai_10` 5:7 아티팩트 분할) / Mobile (대화 탭 ↔ 프리뷰 탭 전환)
* **슬롯 조합**:
  * `header`: `nav_05`(고정 헤더), `nav_04`(워크스페이스 경로), `aut_01`(참여 멤버 아바타 스택), `ico_11`(분할 실행 버튼)
  * `main`: `ai_10`(좌측 대화 + 우측 실시간 아티팩트 캔버스), `ai_01`(추론 대기 3도트), `ai_02`(토큰 스트리밍), `ai_09`(도구 실행 파이프라인 단계), `ai_05`(RAG 출처 각주 팝오버), `form_10`(파일 드래그앤드롭 첨부)
  * `bottom`: `fb_07`(단축키/모델 설명 툴팁), `fb_01`(코드 복사 토스트)
  * `behavior`: `txt_10`(AI 추론 상태 그라데이션 쉬머), `mo_06`(페이드 전환)

## 5. 팀 설정 · 권한(RBAC) · 보안 관리
* **권장 뷰포트**: Desktop (`lay_12` 홀리 그레일 또는 `lay_05` 사이드바 설정)
* **슬롯 조합**:
  * `header`: `nav_04`(설정 > 보안 경로), `nav_02`(상단 설정 탭)
  * `main`: `aut_01`(멤버 아바타 + 초대 모달), `aut_02`(RBAC 역할 관리 표), `aut_03`(API 키 마스킹 & 복사 박스), `aut_05`(패스키 & 2FA 보안 카드), `form_04`(즉시 반영 스위치 토글), `aut_04`(위험 구역 Danger Zone)
  * `bottom`: `fb_04`(영구 삭제 확인 `<dialog>` 모달), `ld_09`(저장 로딩 버튼), `fb_01`(설정 저장 토스트)
  * `behavior`: `fb_06`(프로젝트명 불일치 인라인 오류)

## 6. 모바일 콘텐츠 피드 · 소셜 커뮤니티
* **권장 뷰포트**: Mobile (`Mobile 9:19`) → Tablet (`cnt_04` 마스터-디테일)
* **슬롯 조합**:
  * `header`: `nav_05`(고정 헤더), `nav_02`(추천/팔로잉 상단 탭), `src_01`(검색창)
  * `main`: `ld_08`(당겨서 새로고침), `cnt_03`(피드 리스트) 또는 `lay_10`(메이슨리 그리드), `med_01`(이미지 라이트박스), `med_04`(스레드 댓글 & 이모지 리액션), `nav_08`(무한 스크롤), `ld_02`(초기 스켈레톤)
  * `bottom`: `nav_01`(하단 탭바 + `ind_09` Safe Area), `ico_10`(스피드 다이얼 FAB), `fb_05`(공유/신고 바텀시트)
  * `behavior`: `ld_07`(좋아요·북마크 낙관적 UI), `med_05`(영상 스크롤 시 플로팅 PIP)
